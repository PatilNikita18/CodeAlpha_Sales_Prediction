# 📊 Sales Prediction using Python

## 📌 Project Overview

This project focuses on predicting sales based on advertising spend, target segments, and platforms using Machine Learning.

The project follows a complete data analysis and machine learning workflow:

- Data Loading
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Model Training
- Model Evaluation
- Advertising Spend Impact Analysis
- Business Insights
- Data Visualization

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Models

### 1. Linear Regression

Used as a baseline regression model for predicting sales.

### 2. Random Forest Regressor

Used to capture nonlinear relationships between advertising features and sales.

## 📈 Evaluation Metrics

The models are evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- 5-Fold Cross Validation
